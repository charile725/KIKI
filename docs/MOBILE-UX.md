# 手機優先 UI / UX

主要使用情境為手機上的單手瀏覽、建立分身、詢問穿搭、查看試穿與收藏；桌機沿用原本電商版面。這次沒有變更 Supabase schema、資料權限、推薦與試穿 Adapter。

## 手機操作規劃

- **底部五入口**：首頁、選品、AI 穿搭、我的分身、衣櫃。現在位置會高亮，支援 iPhone 底部安全區域，不需要先打開漢堡選單。
- **註冊與分身**：專注式頁面收起底部導覽與頁尾；分身步驟固定「下一步／完成」於底部，上一頁並列。相機仍提供完整人形框、倒數與重新拍照。
- **首頁**：合併影像與主文案，縮短首屏；建立分身入口在主要手機尺寸第一屏可點到，小高度螢幕另縮短封面。資訊分層、商品維持雙欄。
- **選品**：預設先看商品與搜尋，穿搭助理可由明確按鈕或底部入口開啟；分類與建議問題可橫向滑動。收起助理後仍保留目前推薦內容。
- **AI 穿搭**：查詢送出後收起輸入焦點並捲動到結果，推薦卡片有較完整可讀的理由與整列試穿按鈕。
- **商品詳細**：試穿按鈕固定於底部導覽上方，尺碼、色票與收藏有較大的觸控區。
- **試穿室**：照片保持比例；底部固定收藏或前往衣櫃入口，不必先滑過全部選項。可在下方修改穿搭名稱或重新生成，保存動作沿用原本的資料寫入。
- **衣櫃**：先呈現分身摘要與穿搭收藏；穿著偏好、外部 AI 授權及資料刪除集中於可展開的設定區，仍可完整操作。
- **閱讀與輸入**：主要內容 14–16 px、表單輸入至少 16 px；主要觸控操作 44–52 px。視窗、卡片、通知與狀態延續原本的中性色和綠色系統。
- **軟鍵盤**：透過 VisualViewport 感知可視高度變化，輸入時收起底部導覽與固定試穿操作，降低遮擋；支援 reduced-motion 設定。

## 實作檔案

- `src/mobile.css`：獨立且可檢視的手機版面、尺寸、安全區與操作規則；主斷點 720 px，另補窄／矮螢幕。
- `src/components/MobileNavigation.tsx`：底部導覽、位置狀態與軟鍵盤事件處理。
- `src/App.tsx`：依路由切換一般／註冊與分身／試穿版面。
- `src/pages/Catalog.tsx`：手機預設收起助理、直接開啟入口、保留內容及結果定位。
- `src/pages/Fitting.tsx`：固定收藏與衣櫃操作。
- `src/pages/Wardrobe.tsx`：可展開的偏好／隱私設定。
- `index.html`：`viewport-fit=cover`。

## 驗證

手機測試包含完整註冊到收藏與刪除流程；另針對 320×568、360×740、390×844、430×932 驗證首屏主操作、底部導覽點擊區、無水平溢出、AI 入口切換、輸入字體、鍵盤避讓與商品固定試穿操作。桌機與平板仍跑原本核心流程。

鍵盤與相機測試採瀏覽器模擬，仍需以實體 iOS Safari / Android Chrome 驗收原生鍵盤、瀏海安全區與相機權限。資料庫連線與 AI 模式的既有限制沒有改變。

手機單屏截圖位於 `artifacts/mobile-*-screen.png`；所有測試人物皆為合成測試素材。
